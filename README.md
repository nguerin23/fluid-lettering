# Fluid — Générateur de lettering vectoriel

Un générateur de lettrages organiques en SVG, sans police ni bibliothèque externe.

## Utilisation

Sur le site, saisissez un mot puis cliquez sur **Générer le lettering**. Ajustez ensuite les couleurs et les formes, et exportez le résultat en **SVG** ou **PNG**.

Paramètre facultatif dans l'URL : `?mot=Nicolas`.

## Publier avec GitHub Pages

Dans ce dépôt public, ouvrez **Settings → Pages**.

- **Source** : Deploy from a branch
- **Branch** : main
- **Folder** : /(root)

Enregistrez. Le site sera accessible à l'adresse :

https://nguerin23.github.io/fluid-lettering/

Le fichier `index.html` contient toute l'application ; elle fonctionne côté navigateur.
